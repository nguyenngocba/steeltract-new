# VISUAL001 Inventory Design Analysis

Date: 2026-07-18

## Why Inventory Feels Stronger

Inventory works because it has a clear operating focal point. KPI cards provide
the first scan, charts explain context, and the primary table or map owns most
of the available viewport. Supporting panels stay secondary.

The strongest Inventory pages share these traits:

- KPI section is compact and scannable.
- Tables and maps are visually dominant, not buried beneath equal cards.
- Supporting charts have enough height to be interpreted.
- Right-side panels provide context, not competing primary content.
- Empty states preserve the same card/table height so the workspace does not
  collapse into a blank page.
- Spacing is dense enough for enterprise work but still breathable.

## Composition Ratio

- KPI: 10-15%.
- Charts and summary: 20-25%.
- Main operational workspace: 55-65%.
- Right context: 15-20%.

This became the shared benchmark for VISUAL001.
