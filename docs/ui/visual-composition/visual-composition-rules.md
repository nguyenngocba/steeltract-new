# VISUAL001 Visual Composition Rules

Date: 2026-07-18

## Rules

- Each workspace needs one obvious focal point.
- Tables, queues, boards and catalogs are primary in ERP modules.
- Charts support decisions; they should be large enough to read.
- KPI cards remain compact and should not consume the page.
- Right panels contain context, recent activity, attention or quick facts only.
- Avoid equal-weight card grids unless the route is explicitly a metrics-only
  page.
- Empty states keep the same visual footprint as populated states.
- Use shared cockpit heights and shells before adding module-local layout.

## Shared Implementation

VISUAL001 applies these rules through shared cockpit primitives:

- Larger table heights for primary workspaces.
- Taller medium/large chart heights.
- Stronger card treatment for table and large chart surfaces.
- Denser workspace spacing.
- A more stable table shell with a subtle surface and scroll owner.
