# Inventory Return Dashboard Report

## KPI Cards

The Inventory Return workspace now shows:

- Requested
- Received Today
- Rejected Today
- Pending Quantity

## Analytics

Charts use return request data only:

- `Trạng thái phiếu trả`: status distribution for Requested, Received, Rejected, Accepted.
- `Xu hướng phiếu trả 30 ngày`: daily return request creation count.
- `Top vật tư được trả`: top materials by requested return quantity.
- `Khối lượng chờ nhận`: requested, received, and rejected quantity distribution.

## Inventory Overview Integration

Inventory Overview now includes a `Pending Returns` KPI card.

Clicking it opens:

`/inventory/returns`

## Sidebar

Inventory sidebar was reorganized so Return Requests appears as a primary workspace near Tổng quan, Vật tư, Giao dịch, Tồn kho, and Vị trí kho.
