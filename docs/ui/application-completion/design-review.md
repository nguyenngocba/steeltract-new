# PLATFORM002 Design Review

Date: 2026-07-18

## Reviewed Standards

- KPI-first workspace rhythm.
- Compact Enterprise toolbar/filter placement.
- Table or list as the main operational anchor.
- Right-side panel for context, recent activity, attention or guidance.
- Neutral empty-state language where data contracts are absent.
- Consistent button, input and card density inherited from Inventory.

## Changes Applied

- Dashboard and Production/Components cockpit subtitles now use business
  language instead of source/debug labels.
- Command Center, Analytics and Copilot hero copy now reads as enterprise
  operations copy rather than runtime/developer tooling.
- Inventory location audit chips now label questionable rows as data requiring
  verification instead of demo records.
- Components QC and material stock sections now use operator-friendly data
  freshness labels.

## Remaining Visual QA

Browser screenshots are still required for 1366, 1600, 1920 and ultrawide
widths before freezing this as final visual evidence.
