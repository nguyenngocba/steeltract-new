# Platform Empty State Standard

Date: 2026-07-18

For platform capabilities without backend contracts, the UI must show:

- what the capability is;
- which bounded context should own it;
- which read source exists or is missing;
- what the next implementation step is;
- no fake numbers;
- no demo rows;
- no `Coming Soon`, `TODO`, or temporary placeholder language.

This standard was applied to Settings platform sections and Supplier incomplete
tabs during PLATFORM001.
