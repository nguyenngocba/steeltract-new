# Inventory Comparison

Status: IMPLEMENTED

Inventory feels operational because it answers the manager's first questions in
order:

1. What is the current state?
2. What is at risk?
3. Which records should I inspect?
4. What explains the distribution?
5. What happened recently?

The Golden UX pattern is not the visual skin alone. It is the business
hierarchy:

- KPI first.
- Filter and action controls adjacent to the main table.
- Dashboard tables limited to Top N.
- Full workspaces handle full list operations.
- Side panels are decision support, not decoration.
- Empty space is replaced with activity, queues, distribution or exception
  cases when real data exists.
