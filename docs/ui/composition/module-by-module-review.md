# Module-by-Module Composition Review

## Inventory

Inventory remains unchanged and continues to be the Golden Reference.

## Production

Production already had a table-dominant order registry, but the lower overview
area still used an equal three-card row. The updated composition keeps
manufacturing order work as the dominant surface and changes the lower
composition into one wider production-stage panel with active components and
operation logs in a secondary rail.

## Components

Components Overview already has a dominant registry. The follow-up queue area
used two equal cards, which weakened hierarchy. The update keeps the QC queue
as the broader workspace and makes Ready to Ship a narrower support surface.

## QC

QC Overview has a strong inspection queue. The charts below it were presented
as an equal three-card row. The update makes trend analysis the broader
workspace and moves status/project/NCR summaries into a support rail.

## Suppliers

Supplier directory and supplier evaluation were too close to a split-screen
layout, especially the evaluation detail panel. The update makes the supplier
table/evaluation register the hero workspace and narrows the support panel.

## Settings

Settings capability pages now read more like a configuration catalog. The table
catalog is taller and primary; guidance stays in a narrower right rail.

## Notifications

Notifications now behaves as an operational feed. The feed owns the page and
the selected notification detail is a narrower contextual rail.

## Remaining Modules

Projects, Reports, Command Center, Analytics, Copilot, Marketplace, Workflow,
Digital Twin, Kernel, Federation and Telemetry-like routes still require
browser screenshot certification. Existing shared composition primitives from
VISUAL001 provide the baseline, but route-specific composition should be
reviewed visually before freezing.
