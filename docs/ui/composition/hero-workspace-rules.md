# Hero Workspace Rules

## Primary Surface

The primary surface is the operator's working area:

- Production: manufacturing order / stage / work queue.
- Components: component registry and lifecycle queues.
- QC: inspection queue and trend/decision workspace.
- Suppliers: supplier directory or evaluation register.
- Settings: configuration catalog.
- Notifications: operational feed.

The primary surface should have stable height, independent scroll where needed
and enough width for table or feed scanning.

## Support Rail

The support rail may contain:

- status distribution;
- recent activity;
- selected detail;
- next-step guidance;
- small decision charts;
- readiness or issue summaries.

The rail must not compete with the primary surface. On wide desktop it may be
sticky when that improves scanning. On smaller screens it stacks below.

## Small Dataset Rule

When a list has only a few rows, the page must not collapse into an accidental
empty dashboard. The remaining workspace can be used for activity, statistics,
progress, distribution or a useful empty state.
