# Before and After Analysis

## Before

- Several non-Inventory modules used visually equal card grids after the KPI
  section.
- Some support panels were too wide and competed with the primary feed/table.
- Short datasets could make the working area feel smaller than the surrounding
  secondary cards.
- Settings, Suppliers and Notifications did not always present their core
  identity as a catalog, directory or feed first.

## After

- Production lower overview uses a primary stage workspace with a support rail.
- Components queue area is no longer 50/50; QC queue takes primary width.
- QC analytics is no longer three equal cards; trend owns the row and summaries
  support it.
- Supplier list and evaluation pages keep the table/register as the dominant
  surface.
- Notifications feed now receives the dominant width; detail is contextual.
- Settings foundation pages keep capability catalog as the primary surface.

## Invariants

- No backend changes.
- No API changes.
- No business logic changes.
- No shared component, token, theme or typography changes in this EPIC.
- Inventory was not modified.
