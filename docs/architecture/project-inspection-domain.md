# Project Inspection Domain

Task inspection and handover state is now modeled by `ProjectTaskInspection`.

## Statuses

* `PENDING_INSPECTION`
* `INSPECTION_FAILED`
* `INSPECTION_PASSED`
* `ACCEPTED`
* `HANDED_OVER`

## Dates

* `inspectionDate`
* `acceptedDate`
* `handoverDate`

## Current Scope

Sprint 40PROJ.7 creates the persistence model and API data source. Full QC inspection workflow linking, acceptance documents, and handover certificates remain future workflow work.
