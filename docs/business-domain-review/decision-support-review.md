# Decision Support Review

Status: IMPLEMENTED

## Production Director

Can answer within five seconds:

- Which orders are running.
- Which orders are delayed.
- Which orders are blocked by steel/material readiness.
- Which orders are ready to release.
- How issued/consumed/reserved material flow compares.

## Factory Manager

Can answer within five seconds:

- Current work order queue.
- Stage distribution.
- Active components under production.
- Material shortage points.
- Recent production activity.

## Workshop Supervisor

Can answer within five seconds:

- Which MO/WO needs action.
- Which due dates are risky.
- Which orders have low progress.
- Which material issues block execution.

## Component Tracking Manager

Can answer within five seconds:

- Current lifecycle distribution.
- Which components are waiting for QC.
- Which components are ready to ship.
- Which project has most active components.
- Recent component changes.
